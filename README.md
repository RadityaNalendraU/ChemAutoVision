# Requirements
- [Docker](https://docs.docker.com/engine/install/)
- [Docker Compose](https://docs.docker.com/compose/install/)
- NVIDIA Container Toolkit

## Packages

This project uses [Poetry](https://python-poetry.org/) as the package manager. 
All dependencies and their versions are defined in `pyproject.toml`.

# Environment Setup
## When using Docker
### Create docker image
```
docker build -t [image_name] .
```

### Launch Container
```
docker run  -d --gpus all -v $(pwd):/chemAutoVision [image_name]
```

## When using Docker Compose
### Launch Container
```
docker compose up -d
```

You can confirm the launched container with the following command.
```
docker ps
```

## Library Install

You can access the container with the following command.

```
docker exec -it [container_id] bash
```

After accessing the container, run the following command in the directory containing `pyproject.toml`. 

```
poetry install
```

# Dataset
All datasets used in the manuscript are generated with the following command. Dataset splitting is also performed.

[task_name] accepts one of the following: FreeSolv, ESOL, Lipo, BBBP, hERG, P-gp, CYP3A4

```
docker exec -w /chemAutoVision/src [container_id] python3 generate_data.py --task_name [task name]
```

The generated dataset is saved to `/chemAutoVision/data`.
And the generated skeletal formula images are saved `/chemAutoVision/data/images/[task_name]`

The datasets for CYP3A4 inhibition, hERG inhibition, and P-gp substrate prediction were obtained from [Han et al.](https://doi.org/10.1021/acs.jcim.4c02122). In the original study, the files labeled `valid` were used as external validation datasets. Therefore, these external datasets were excluded from the data used for model training and evaluation in this study. For each task, the corresponding `train` and `test` files were concatenated and used as the source dataset.

# Model training
Model training and evaluation are performed with following command.
The trained models are saved in `/chemAutoVision/models`.

```
# Classification task
docker exec  -w /chemAutoVision/src [container_id] \
    python3 experiment_image_classifier.py \
        --gpu 0 \
        --task_name BBBP \
        --epochs 200 \
        --model_name autokeras \
        --batch_size 8 \
        --max_trials 100 \
        --execute_data_aug \
        --seed 99

docker exec  -w /chemAutoVision/src [container_id] \
    python3 experiment_image_classifier.py \
        --gpu 0 \
        --task_name BBBP \
        --epochs 200 \
        --hp_tuning keras_tuner \
        --model_name resnet18 \
        --batch_size 8 \
        --max_trials 100 \
        --seed 99 \
        --execute_data_aug 

# Regression task
docker exec  -w /chemAutoVision/src [container_id] 
    python3 experiment_image_regressor.py \
        --gpu 0 \
        --task_name FreeSolv \
        --epochs 200 \
        --model_name autokeras \
        --batch_size 8 \
        --max_trials 100 \
        --execute_data_aug \
        --seed 99

docker exec  -w /chemAutoVision/src [container_id] \
    python3 experiment_image_regressor.py \
        --gpu 0 \
        --task_name FreeSolv \
        --epochs 200 \
        --hp_tuning keras_tuner \
        --model_name resnet18 \
        --batch_size 8 \
        --max_trials 100  \
        --seed 99 \
        --execute_data_aug 
```

# Model Prediction
The prediction results obtained by evaluating the trained models on the test data, together with the corresponding ground-truth values, are stored under `/chemAutoVision/results`.

Predictions generated by newly trained models are also stored under `/chemAutoVision/results`.

# Confirm metrics of trained model
## MLflow Tracking
Model training settings and evaluation metrics are recorded using MLflow. 
The recorded data, including parameters, metrics, and tags, is saved under `/chemAutoVision/mlruns/[experiment_id]`.

The recorded results can be viewed and compared using the [MLflow Tracking UI](https://mlflow.org/docs/latest/ml/tracking/).

You can start MLflow Tracking UI with following command.

```
docker exec -it [container_id] \
    mlflow ui \
    --host 0.0.0.0 \
    --port 5000 \
    --backend-store-uri /chemAutoVision/mlruns \
    --gunicorn-opts "--timeout 300"
```

After starting MLflow Tracking UI, open `http://localhost:5000` in your browser.
